# MAX Chat на GREEN-API

Минималистичный веб-чат на React для отправки и получения **текстовых** сообщений в MAX через [GREEN-API](https://green-api.com/max).

## Что реализовано

- Вход по `idInstance` и `apiTokenInstance`
- Создание чата по номеру телефона.
- Отправка текста.
- Получение ответов.
- Входящие от новых собеседников автоматически создают чат; сообщения, отправленные с телефона, тоже отображаются.
- История и список чатов сохраняются в `localStorage` браузера (отдельно для каждого инстанса).

## Подготовка инстанса GREEN-API

1. Создайте MAX-инстанс в [личном кабинете](https://console.green-api.com) и авторизуйте аккаунт MAX.
2. В настройках инстанса оставьте **пустым** `webhookUrl` и включите уведомления: входящие, исходящие (`incomingWebhook`, `outgoingWebhook`: `yes`).
3. Скопируйте `idInstance`, `apiTokenInstance` (и `apiUrl`, если он отличается от `https://green-api.com`).

Примечание: `checkAccount` поддерживает только российские (`7…`) и белорусские (`375…`) номера.

## Локальный запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка: `npm run build` (результат в `dist/`), предпросмотр: `npm run preview`.

## Проверка сценария

1. Откройте сайт, введите `idInstance` и `apiTokenInstance`.
2. Введите номер получателя (например `79991234567`) и нажмите «+».
3. Напишите сообщение и отправьте (Enter; Shift+Enter — перенос строки).
4. Ответьте с аккаунта получателя в MAX — ответ появится в чате в течение нескольких секунд.

## Структура

- `src/api/greenApi.ts` — обёртка над методами GREEN-API
- `src/useChats.ts` — состояние чатов, отправка, polling уведомлений
- `src/components/` — `Login`, `Messenger` (список чатов), `ChatWindow`
- `src/styles.css` — оформление (светлая/тёмная темы, адаптив)

## Безопасность

Токен хранится в `localStorage` браузера и отправляется только на GREEN-API. Для продакшена рекомендуется проксировать запросы через бэкенд.
